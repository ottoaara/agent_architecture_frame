Vendor: AWS Wickr (Amazon Web Services), enterprise secure messaging. Public information gathered October 2026.

Company and services: Wickr was founded in 2012 and acquired by Amazon Web Services in June 2021; it is now an AWS managed service. Provides end-to-end encrypted one-to-one and group messaging, voice and video calls, file and screen sharing, and location sharing, with administrator controls, message expiry and burn-on-read. Also offered as Wickr Enterprise (self-hosted) and in AWS GovCloud. Published pricing: Standard about USD 5 per user per month, Premium about USD 15 per user per month (custom data retention, unlimited admin controls, 5 GB attachments), guest add-on about USD 2 per user per month. The free consumer app Wickr Me was closed on December 31, 2023.

Security: 256-bit end-to-end encryption; every message, call and file uses a unique key, and content is encrypted locally on the device. An optional data retention module lets organisations keep an encrypted copy of communications for compliance; when enabled, this deliberately creates an archive outside the end-to-end model that must be secured.

Financial stability: Backed by Amazon (AWS), so vendor insolvency risk is very low. The main risk is product-strategy risk: AWS has retired the consumer product, and a niche service inside a very large provider can be repriced, folded into other services or deprecated with notice.

Regulatory compliance: FedRAMP High authorisation in AWS GovCloud (US-West) (March 2024); DoD Cloud Computing SRG Impact Level 4 and 5; HIPAA eligible; ISO 27001; SOC 1, 2 and 3. Data retention and records features support regulated industries (e.g. finance record-keeping). Subject to US jurisdiction (including the CLOUD Act) as a US company, which matters to EU customers with data-sovereignty requirements. Check the regions on offer against data-residency needs.
